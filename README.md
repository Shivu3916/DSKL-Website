# Dr. Shivram Karanth Layout — Application Portal

Static website for an independent assistance bureau helping applicants with BDA
Dr. Shivram Karanth Layout (DSKL) site applications across all 9 sectors in
North Bengaluru.

## Structure

- `index.html`, `about.html`, `contact.html`, `faq.html`, `procedure.html` — main pages
- `sector1.html` – `sector9.html` — per-sector detail pages
- `styles.css`, `script.js` — shared styles and interactive behavior
- `assets/images/` — site imagery (logos, hero, sector maps)
- `manifest.json` — PWA manifest
- `sitemap.xml`, `robots.txt` — SEO
- `google2b6793271aeeeccc.html` — Google Search Console site verification

## Deployment

Hosted via GitHub Pages, served under the custom domain configured in `CNAME`.
